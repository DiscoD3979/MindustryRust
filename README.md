# MindustryRust

Минимальный клиент для обычных серверов Mindustry 160.8, написанный на Rust.

**Внимание:** результат самый минимальный и, по моей оценке, очень плохой.
Это эксперимент, а не полноценная замена игре: нет полной синхронизации
мира и многих других функций. (проект полностью сделан ИИ)

## Что есть

1. Окно с меню: сервер, порт, имя.
2. Подключение к обычному серверу Mindustry 160.8.
3. Отправка сообщений в чат и отображение входящих сообщений.
4. Отображение карты спрайтами из официальных ассетов Mindustry (с ошибками).
5. HUD с FPS, быстрые сервера, кнопки отмены подключения и выхода.
6. Движение своим юнитом и стрельба.

Ассеты взяты из официального репозитория Mindustry:
https://github.com/Anuken/Mindustry

## Запуск

Готовый exe лежит в `target/release/mindarust.exe`.

- Без аргументов открывается меню.
- С аргументами подключение начинается сразу:

```
mindarust.exe <host> <port> <name>
```

Например:

```
mindarust.exe 127.0.0.1 6567 MindaRust
```

## Управление

- WASD или стрелки — движение своего юнита, Shift — ускорение; камера следует за юнитом.
- Левая кнопка мыши — стрельба, наведение — курсором.
- Правая кнопка мыши + тянуть — смещение камеры относительно юнита.
- Колесо мыши — приближение/отдаление карты.
- Enter — открыть чат; Enter — отправить и закрыть; Esc — закрыть чат.
- Esc вне чата — выйти с сервера.
- HUD сверху показывает FPS и статус подключения.

FPS в HUD относится к этому Rust-рендеру; с числами Java-клиента его
напрямую сравнивать нельзя.

## Идентификатор

Рядом с exe создаётся файл `identity.bin` с UUID/USID. Он нужен, чтобы сервер
не банил за частую смену идентификатора. Не удаляйте его при частых
перезапусках.

## Сборка

Нужны Rust и стандартные для вашей ОС инструменты сборки. В корне проекта:

```
cargo build --release
```

Готовый файл появится в `target/release/`. Перед пересборкой закройте
запущенный клиент.
