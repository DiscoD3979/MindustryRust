# MindustryRust

Mindustry Client, переписанный на Rust.

Внимание: результат самый минимальный и, по моей оценке, очень плохой.

1. Минимальный результат.
2. Можно зайти на любой сервер (надеюсь).
3. Можно написать в чат — сообщение отправляется на сервер.
4. Много багов, сделано всего за несколько часов.
5. Карта видна, но текстуры местами ломаются.

Ассеты взяты из официального репозитория Mindustry:
https://github.com/Anuken/Mindustry

Запуск: `target/release/mindarust.exe [host] [port] [name]`.
